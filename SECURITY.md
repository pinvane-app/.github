# Security policy

[한국어](#보안-정책)

## Report a security problem privately

Please **do not open a public issue** for a security problem.

E-mail **support@pinvane.com** with the subject **"Security"** and include:

- the Pinvane version (`pinvane version`) and your Windows version;
- what the problem is and what someone could do with it;
- the steps to reproduce it, using a small sample project — **never a real drawing, customer data, keys or passwords**.

We aim to confirm that we received your report within 24 hours, and will follow up at the same address after we have checked it. Please keep the details private until then.

## Supported versions

Pinvane is in pre-release testing. After the first release, security fixes go into the newest version; please update to it.

## Scope

Pinvane (the Windows app, its local editor and viewer, its local MCP server and its command line), the update information it fetches from pinvane.com, and the website https://pinvane.com.

## 보안 정책

보안 문제는 **공개 이슈로 올리지 마세요.**

**support@pinvane.com** 으로 제목 **「Security」** 를 붙여 메일을 보내 주세요. 다음을 적어 주세요.

- Pinvane 판(`pinvane version`)과 Windows 판
- 무엇이 문제이고, 그것으로 누가 무엇을 할 수 있는지
- 재현 순서 — 작은 견본 프로젝트로. **실제 도면 · 고객 자료 · 키 · 비밀번호는 넣지 마세요.**

받았다는 답은 24 시간 안을 목표로 드리고, 확인한 뒤 같은 주소로 다시 연락드립니다. 그때까지 자세한 내용은 공개하지 말아 주세요.

지원 판: 출시 전 시험 중입니다. 첫 출시 뒤에는 보안 고침이 가장 새 판에 들어갑니다 — 새 판으로 올려 주세요.
