# Getting help with Pinvane

[한국어](#pinvane-도움-받기)

- **User guide:** [pinvane-app/pinvane](https://github.com/pinvane-app/pinvane#readme) — getting started, connecting your AI app, the command line, the check list and outputs, FAQ.
- **Download and install:** https://pinvane.com/download/ or [Releases](https://github.com/pinvane-app/pinvane/releases) — check the SHA-256 before you run the installer ([how](https://github.com/pinvane-app/pinvane/blob/main/docs/en/getting-started.md#install)).
- **Public questions and problem reports:** [open an issue](https://github.com/pinvane-app/pinvane/issues/new/choose).
- **Private matters** (license, payment, anything you do not want public): support@pinvane.com — answers in Korean or English, aiming for two business days (Korean time). Replies are written by Pinvane's support AI and say so; write "person" if you want a person to look.
- **Security problems:** report privately — [SECURITY.md](https://github.com/pinvane-app/.github/blob/main/SECURITY.md).

**Please never attach drawings, project files, customer names or file paths.** We do not need them. If a problem must be shown, make a small sample project with a few parts that shows the same thing.
